# Glossary: 天若有情 The Witness of Time (TVB, 1980)

1980 Hong Kong and mainland China. Same method as `translationclaude.md`.
This file replaces the 生死訟 glossary for this series. Agents add new names in
their report; the coordinator merges them here between episodes.

**Names:** pinyin, as established below. Keep a name exactly as first fixed here.
Where the Chinese uses a proper form and a familiar form, keep both, as the 生死訟
glossary does (馬陳玉卿 / 玉卿): 港生 Gangsheng / 阿港 Ah Gang.
