# Glossary: 天若有情 The Witness of Time (TVB, 1980)

1980 Hong Kong and mainland China. Same method as `translationclaude.md`.
Agents add new names in their report; the coordinator merges them here between
episodes.

**Names:** pinyin. Keep a name exactly as fixed here. Where the screen uses a
proper and a familiar form, keep both (as the 生死訟 glossary does): 港生 Gangsheng
/ 阿港 Ah Gang.

**Continuity — read this before naming anyone.** The series follows the 華 family
across decades. 華京生 (the boy of eps 1–4, pet name 大毛) *is* the grown
**生哥 / 華先生 "Brother Sheng"** of eps 5 onward: same man, not a new character.
港生 / 阿港 is his younger brother. When an episode's cast seems to have nothing in
common with the previous one, check for a time jump before inventing new people.
